# Вечерний английский — Mini App + бот

Приложение на 168 вечеров: карточки, промпт дня одной кнопкой, утренний опрос про сон,
статистика. Разговор остаётся в ChatGPT — приложение только отдаёт промпт.

```
build.py                   парсит план и колоду -> data.js, ставит метку версии в index.html
index.html app.js style.css data.js    Mini App (чистый JS, без сборки) — на GitHub Pages
bot.py                     будильник и резервные копии — на VPS
english-168-evenings.txt   план на 168 дней
english-anki-deck.csv      1008 карточек
```

---

## 0. Собрать данные

Нужен только Python 3.9+, никаких зависимостей.

```bash
python3 build.py
```

Должно напечатать `OK дней: 168` и `OK карточек: 1008`. Если данные не сходятся —
скрипт падает и пишет, в каком дне и что именно не разобралось. Тогда чинить исходный
файл, а не `data.js`.

**Запускай `build.py` после каждой правки `app.js`, `style.css` или плана.**
Он пересчитывает метку версии `?v=...` в `index.html`. Без этого Telegram и GitHub Pages
ещё сутки будут открывать на телефоне старую версию — это самая частая причина
«я всё исправил, а ничего не поменялось».

---

## 1. Создать бота в BotFather

1. В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — любое («Вечерний английский»). Юзернейм — заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456789:AAF...`. Это пароль от бота, никому не давай.
4. Узнай свой числовой id: напиши [@userinfobot](https://t.me/userinfobot), он ответит `Id: 123456789`.

---

## 2. Выложить Mini App на GitHub Pages

1. Создай репозиторий на GitHub, например `english-evenings` (можно приватный —
   Pages работает и так на платном аккаунте; на бесплатном нужен публичный).
2. Залей в него файлы:

```bash
cd english-evenings
git init
git add index.html app.js style.css data.js build.py bot.py requirements.txt README.md .gitignore
git add english-168-evenings.txt english-anki-deck.csv
git commit -m "Вечерний английский"
git branch -M main
git remote add origin https://github.com/ЛОГИН/english-evenings.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`. Save.
4. Через минуту адрес будет такой: `https://ЛОГИН.github.io/english-evenings/`
   Открой его в обычном браузере — должен появиться «День 1». Если пусто, подожди ещё
   пару минут: первая сборка Pages бывает небыстрой.

`.env` и `state.db` в репозиторий не попадут — они в `.gitignore`.

---

## 3. Привязать адрес к боту

**Кнопка меню** (синяя кнопка слева от поля ввода):

1. BotFather → `/mybots` → выбери бота → **Bot Settings → Menu Button → Configure menu button**.
2. Вставь адрес `https://ЛОГИН.github.io/english-evenings/`, затем название кнопки, например `Вечер`.

Бот при старте выставляет эту кнопку и сам, но через BotFather надёжнее.

**Кнопки в сообщениях** настраивать не нужно — бот строит их из `MINIAPP_URL`.

---

## 4. Настроить и запустить bot.py

Создай `.env` рядом с `bot.py` (шаблон — в `.env.example`):

```
BOT_TOKEN=123456789:AAF...
CHAT_ID=123456789
MINIAPP_URL=https://ЛОГИН.github.io/english-evenings/
```

Адрес — **со слешем на конце**.

Локальная проверка:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

В логе должно быть `бот запущен, день 1, 168 дней в плане`. Напиши боту `/start` —
он ответит и поставит кнопку клавиатуры «Открыть приложение».

### Нажми `/start` хотя бы один раз

Telegram разрешает приложению отправить данные обратно в чат (`sendData`) **только**
если оно открыто с кнопки клавиатуры. Поэтому:

* для обычного вечера открывай приложение как угодно — с кнопки в сообщении или из меню;
* для **экспорта** и чтобы работал `/stats` — открывай кнопкой «Открыть приложение»
  на клавиатуре, которую даёт `/start`.

### На VPS через systemd

```bash
sudo mkdir -p /opt/evenings
sudo chown $USER:$USER /opt/evenings
# скопируй в /opt/evenings: bot.py build.py english-168-evenings.txt english-anki-deck.csv requirements.txt .env
cd /opt/evenings
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

`/etc/systemd/system/evenings.service`:

```ini
[Unit]
Description=Вечерний английский — бот
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ПОЛЬЗОВАТЕЛЬ
WorkingDirectory=/opt/evenings
ExecStart=/opt/evenings/.venv/bin/python3 /opt/evenings/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now evenings
systemctl status evenings
journalctl -u evenings -f          # смотреть лог
```

Часовой пояс задан внутри бота (`Europe/Moscow`), системный не важен.
Перезапуск безопасен: бот помнит, что уже отправлял сегодня, и не шлёт сообщения дважды.

### Или попроще, через screen

```bash
screen -S evenings
cd /opt/evenings && .venv/bin/python3 bot.py
# выйти, оставив работать: Ctrl+A, затем D
screen -r evenings                 # вернуться
```

## 4b. Временный режим: всё на Mac, одной командой

Пока нет GitHub Pages и VPS, приложение и бот поднимаются прямо с ноутбука:

```bash
cd ~/Desktop/english-evenings && ./start.sh
```

Скрипт сам: пересобирает `data.js`, кладёт **только** четыре файла приложения в `public/`,
поднимает локальный сервер, открывает публичный HTTPS-адрес через `localhost.run`
(без регистрации), прописывает адрес в `.env` и запускает бота. Бот при старте сам
перевешивает кнопку меню на новый адрес, так что менять что-то руками не нужно.

Остановить — `Ctrl+C` в том же окне.

**Ограничения, о которых надо помнить:**

* Работает, только пока Mac включён и не спит. Уснул в 22:00 — сообщение не придёт.
  Имеет смысл поставить «Не давать засыпать» на вечер (Системные настройки → Экран блокировки).
* Адрес туннеля меняется при каждом запуске. `start.sh` это чинит сам, но если Telegram
  успел закэшировать старый — закрой Mini App свайпом и открой заново.
* В `public/` копируются только `index.html`, `app.js`, `style.css`, `data.js`.
  Туда намеренно не попадают `.env`, `bot.py` и `state.db` — иначе токен уехал бы в интернет.

Постоянный вариант — разделы 2 (GitHub Pages) и 4 (VPS). Как только появятся, временный
режим больше не нужен: пропиши в `.env` постоянный `MINIAPP_URL` и запускай `bot.py` напрямую.

## 5. Что делает бот

| Когда | Что |
|---|---|
| 22:00 | «День N — тема» с кнопкой, открывающей приложение |
| 22:58 | «Finish. Свет.» |
| 09:00 | «Как спалось?» с кнопкой |

Команды: `/today` — прислать день ещё раз, `/day N` — поставить текущий день
(кнопка в ответе откроет приложение сразу на нём), `/stats` — краткая статистика
из последнего экспорта.

## 6. Резервная копия

Состояние живёт в Telegram CloudStorage — оно привязано к аккаунту и переезжает
вместе с ним на новый телефон. Отдельная копия нужна на случай «снёс приложение
и почистил данные».

**Сделать копию.** Открой приложение кнопкой на клавиатуре → шестерёнка → **Экспортировать**.
Полное состояние копируется в буфер обмена и показывается текстом; в чат уходит сводка
(целиком оно в сообщение Telegram не помещается — там лимит 4 КБ). Сохрани текст
куда-нибудь: в «Избранное» в Telegram, в заметки, в файл.

**Восстановить.** Шестерёнка → вставь текст в поле **Импорт** → **Импортировать**.
Состояние заменится целиком: карточки, сделанные дни, ответы про сон, настройки.
Если текст битый — приложение скажет, что именно не так, и ничего не тронет.

**Копии на стороне бота.** Каждый экспорт бот складывает в `state.db` (последние 30 штук).
Файл лежит рядом с `bot.py`:

```bash
sqlite3 /opt/evenings/state.db "SELECT ts, length(payload) FROM backups ORDER BY id DESC LIMIT 5;"
sqlite3 /opt/evenings/state.db "SELECT payload FROM backups ORDER BY id DESC LIMIT 1;" > backup.json
```

Содержимое `backup.json` можно вставить в поле «Импорт».

## 7. Если что-то не так

**Приложение открылось старой версией.** Запусти `python3 build.py`, закоммить
изменившийся `index.html` и запушь. Метка `?v=...` заставит Telegram перечитать файлы.
Дополнительно помогает закрыть Mini App свайпом и открыть заново.

**«data.js не загрузился или собран неверно».** Запусти `python3 build.py` и залей `data.js`.

**Кнопка «Скопировать промпт» говорит, что буфер недоступен.** Такое бывает, если
Telegram не дал доступ к буферу. Промпт при этом показан ниже и уже выделен —
зажми и скопируй вручную. Шаг всё равно засчитается.

**День в приложении и в боте разошлись.** Приложение — источник правды, оно двигает день
само после Finish. Бот узнаёт день из экспорта. Если разошлись — `/day N` в боте, затем
открой приложение кнопкой из ответа.

**`/stats` пишет, что статистики нет.** Сделай экспорт, открыв приложение кнопкой
клавиатуры из `/start`.

## 8. Как устроено состояние

Всё в `Telegram.WebApp.CloudStorage`. Состояние пакуется в компактную строку и режется
на куски по 3500 символов: на полном прогоне 168 вечеров это 6 кусков и 13 ключей
(лимиты Telegram — 4096 байт на значение и 1024 ключа, запас четырёхкратный).

Запись атомарная: куски пишутся в «теневое» поколение ключей, и только потом одним
ключом переключается манифест. Обрыв связи на середине сохранения не портит уже
записанное, а если текущее поколение окажется испорченным — приложение само поднимется
с предыдущего.
